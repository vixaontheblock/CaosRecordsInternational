# Fuentes locales

Big Shoulders Display e Inter, subconjuntos Latin variables (peso 100–900), conservados de la compilación funcional del proyecto. Incluyen caracteres del español. Se cargan mediante next/font/local y ya no requieren descargar archivos de Google Fonts durante next build.

Licencias SIL Open Font License incluidas junto a los archivos. Fuentes de las licencias:
- https://raw.githubusercontent.com/google/fonts/main/ofl/bigshouldersdisplay/OFL.txt
- https://raw.githubusercontent.com/google/fonts/main/ofl/inter/OFL.txt

Referencia: https://nextjs.org/docs/14/app/building-your-application/optimizing/fonts#local-fonts
